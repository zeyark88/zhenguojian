## 二、这是什么（摘自上游）

Flutter 多端独立短剧应用（原名“短剧库 APP”）。站源请求、解析、下载和播放均在设备上完成，不依赖旧项目或自建服务。

| 编译方式 | 应用名称 | 可用站源 |
| --- | --- | --- |
| 默认，不加参数 | 红果鉴（独立包名 `com.duanju.duanju_app.hongguo`，自动生效，可与真果鉴共存） | 红果 + 韩小圈 + 鬼片（常用三源，直接显示，无需密码锁） |
| 构建脚本加 `--all-sources` | 真果鉴（主包名 `com.duanju.duanju_app`，老用户可覆盖安装升级） | 全部 10 个站源：红果/韩小圈/鬼片直显；黄豆、黄剧、野果、黄果剧场、黄果 AI、黄果旧版、蓝果经站源密码锁解锁后显示 |

这是编译期选项，应用内不能切换版本。标题、桌面名称与电视横幅随编译选项变化；界面、站源调用与下载调度同时限制可用站源；两个版本包名不同、可同时安装。

## 三、本仓库相对上游的源码修改

功能裁剪：

1. **移除应用内更新模块** —— 删除启动检查更新、关于页“检测新版本”入口、APK 下载安装逻辑，同时移除 `REQUEST_INSTALL_PACKAGES` 权限与对应 FileProvider。升级需自行重新构建。
2. **移除关于页应用内署名** —— 上游在“关于”对话框中署名原作者与维护者；本构建移除了该应用内条目（原作者与出处信息改由本 README 声明，见第一章）。
3. **双包自动共存（v0.9.0 起自动，无需手改）** —— 借鉴上游 0.9.0 独立包名方案：「红果鉴」自动使用独立包名 `com.duanju.duanju_app.hongguo`，「真果鉴」保持主包名 `com.duanju.duanju_app`，两版可各自编译、独立安装、同时共存；真果鉴老用户可直接覆盖安装升级。

交互改动：

4. **启动直达主框架** —— 移除启动开屏页（品牌页 + 转圈遮挡），进入应用立即显示带导航的完整框架（首页/发现/追剧/最近观看/下载均可立即操作），首页数据在框架内以骨架屏占位加载。
5. **骨架屏加载提示** —— 多源加载时显示“正在从 N 个站源加载，可先看其他标签”。

性能优化：

6. **Dart AOT 混淆与符号剥离**（`--obfuscate --split-debug-info`），缩减 libapp.so 并加快加载。
7. **Go 核心软内存上限 512MB**（`native/core/app_memory_limit.go`），约束堆水位，降低与视频解码库共存时被系统查杀的概率。
8. **图片缓存峰值收敛 100MB → 64MB**（封面已按 440 宽下采样）。
9. **启动路径并行化**（SharedPreferences 与设备检测并行执行）。
10. **首页网格 RepaintBoundary 重绘隔离**。
11. **下一集预载触发提前 600ms → 350ms**（保留防抖）。
12. **多源目录并发提升** —— Go 全局目录并发 3 → 6、同源请求间隔 250ms → 150ms（均在原设置项允许范围内），Dart 目录 worker 并发 2 → 6。

构建修正：

13. **锁文件保持上游原版** —— 全程使用 `--enforce-lockfile` 由构建脚本镜像转换，杜绝依赖漂移（曾因手动 `pub get` 导致 `shared_preferences_android` 升到 2.5.0，与混淆构建冲突引发启动崩溃，已修复并回归锁定 2.4.28）。**构建时请勿绕过构建脚本手动执行 `flutter pub get`。**
14. **Release 签名方案说明** —— 自行构建时可用 `apksigner` 附加 `--v1-signing-enabled true --v2-signing-enabled true --v3-signing-enabled true`，对各类安装器有更好的兼容性。

**TV 遥控修复（v0.9.1+86a，真机反馈）：**

37. **首页控件条遥控聚焦** —— 根因：整页按键监听把上/下键全部消费为「切剧」、确认键全部消费为「播放/暂停」，底部控件条（进度行 + 倍速/清晰度/选集/追剧/弹幕/投屏/连播）永远拿不到焦点。引入「画面焦点 ↔ 控件条焦点」二模型：控件条可见时按「下」聚焦首按钮，左右在按钮间移动，「上」逐行退回画面；确认键选中按钮，不再误触播放/暂停。
38. **全屏层遥控全量修复** —— 全屏层自 0.2.28 起是独立路由，此前**没有任何按键监听**：遥控器在全屏里播放/暂停、切集、聚焦控件条全部失效。现已对齐手机全屏手势：确认键播放/暂停 + 弹控件条，「上/下」切上一/下一（连播本剧/单剧切集，多剧切部），控件条可见时「下」聚焦控件条。
39. **详情页遥控聚焦修复** —— 根因：详情是异步加载的，路由进入瞬间播放按钮还是禁用态，FilledButton 的 autofocus 在那一刻被跳过；数据就绪后按钮可用但 autofocus 不会重放，焦点停在路由级 FocusScope 上，选集区与底部「下载/立即播放」全部无法聚焦。修复：加载完成后若本页未持有焦点，补一次焦点到播放按钮；焦点在位时上下左右可自然到达选集网格、翻页器与底部操作栏。

**保留上游 0.7.x 全部官方功能与修复**，包括：0.7.17 红果播放取流改为「注册匿名设备身份 + 无签名」优先、六头签名兜底、0.7.16 红果站源完整六头签名修复与开屏超时兜底、0.7.15 切集闪帧修复、0.7.14 连播跟手动画、0.7.13 预加载提前到开播 3 秒、0.7.12 方向锁定手势与移动网络只拦第 1 个视频、0.7.10-0.7.11 横屏手势翻页阈值修复、0.7.8 亮度改为窗口亮度（可超过系统亮度）、0.7.5 全屏手势分工与系统音量、0.7.4 全屏连播控件与移动网络切线路修复、0.7.3「移动网络下自动播放」开关与停预加载、0.7.2 全屏横屏手势与首页剧类筛选、0.7.1 自动更新节流、0.7.0 代理失败自动直连与黄果剧场换域名等。

## 三·五、本版使用说明（手机 / 平板 / 电视）

### 设备自适应
安装后按设备自动切换：**手机** 底部导航 + 竖滑播放；**平板**（屏幕宽度 ≥600dp）自动启用大屏侧栏、详情双栏与更大的字体；**电视**（leanback）启用遥控器主题。可在「设置」里手动指定 `displayMode`（自动/电视/平板）。

### DLNA 投屏
播放器控件「投屏」→ 搜索同一 Wi-Fi 的 DLNA 设备 → 选中即投。红果加密流与需 Referer 的源经**本机中继**转发（电视拉手机），换集自动续投；再点投屏按钮断开。

### 电视遥控器
- **播放/暂停**：播放键 / 确认键（DPAD_CENTER）/ 回车 / 空格，并顺带弹出控件条
- **控件条（0.9.1 新增）**：竖屏控件条可见时按「下」聚焦底部控件条（倍速/清晰度/选集/追剧/弹幕/投屏/连播及进度行）；左右键在按钮间移动，「上」逐行退回画面，确认键选中
- **切集/切部**：竖屏画面焦点时「下」=下一部、「上」=上一部；全屏内「下」=下一、「上」=上一（连播本剧/单剧切集，多剧切部，边界只提示）
- **详情页（0.9.1 修复）**：进入详情后焦点落在底部「立即播放」，上下左右可到达选集网格/翻页/下载/播放
- **返回键**：非全屏时回当前剧详情页（可看简介/选集），全屏时退出全屏
- **密码锁**：底部导航连点「最近观看」6 次唤出

### 弹幕（仅红果源）
播放器控件条提供独立「弹幕」按钮（竖屏与全屏），开关持久化。

### 站源密码锁
默认仅显示红果/韩小圈/鬼片；其余源（黄豆/黄剧/野果/黄果剧场/黄果AI/黄果旧版/蓝果）需启用密码锁并解锁后显示，或关闭密码功能直接全显。解锁状态本次运行有效，重启恢复。

### 红果源说明
红果取流采用「设备身份 + 无签名」优先、六头签名兜底、备用网页/中转兜底；被间歇风控空体时自动换设备身份 + 换 UA 重试。

### 手势速查

## 五、从源码构建

需 Go 工具链编译原生核心生成 `libduanju_core.so`（构建脚本自动完成，无需预编译库）。

**环境要求**：Flutter（版本与上游 `pubspec.yaml` 约束一致）+ Go + JDK 17 + Android SDK（platform 36 / build-tools / NDK）。

**步骤**：

1. 配置自己的签名（仓库不含任何密钥）：在 `android/` 下放置你的 `key.properties` 与 keystore 文件；
2. 构建“真果鉴”（全站源）：

   ```sh
   python3 scripts/build_android.py --abi arm64-v8a --all-sources
   ```

3. 构建“红果鉴”独立包名共存版（仅三源直显，无密码锁需求）：包名已由构建脚本自动设为 `com.duanju.duanju_app.hongguo`，直接执行：

   ```sh
   python3 scripts/build_android.py --abi arm64-v8a
   ```

说明：

- **必须在纯英文路径下构建**（中文路径会导致工具链失败）。
- 构建时不要设 HTTP 代理；访问 GitHub 时才需要代理。
- 构建脚本自带国内镜像选项（`--cn-mirrors`）与锁文件防漂移保护，请勿绕过脚本手动执行 `flutter pub get`。
