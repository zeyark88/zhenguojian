## 二、这是什么（摘自上游）

Flutter 多端独立短剧应用（原名“短剧库 APP”）。站源请求、解析、下载和播放均在设备上完成，不依赖旧项目或自建服务。

| 编译方式 | 应用名称 | 可用站源 |
| --- | --- | --- |
| 默认，不加参数 | 红果鉴 | 仅红果 |
| 构建脚本加 `--all-sources` | 真果鉴 | 红果、黄豆、黄剧、黄果剧场（原黄果视频）、黄果 AI、黄果旧版 |

这是编译期选项，应用内不能切换版本。标题、桌面名称与电视横幅随编译选项变化；界面、站源调用与下载调度同时限制可用站源。

## 三、本仓库相对上游的源码修改

功能裁剪：

1. **移除应用内更新模块** —— 删除启动检查更新、关于页“检测新版本”入口、APK 下载安装逻辑，同时移除 `REQUEST_INSTALL_PACKAGES` 权限与对应 FileProvider。升级需自行重新构建。
2. **移除关于页应用内署名** —— 上游在“关于”对话框中署名原作者与维护者；本构建移除了该应用内条目（原作者与出处信息改由本 README 声明，见第一章）。
3. **可选双包共存** —— 提供将“红果鉴”改为独立包名 `com.duanju.duanju_app.hongguo` 的构建方式，使全站源版与单源版可各自编译、独立安装（构建期决定，见第五章构建说明第 3 步）。

交互改动：

4. **启动直达主框架** —— 移除启动开屏页（品牌页 + 转圈遮挡），进入应用立即显示带导航的完整框架（首页/发现/追剧/最近观看/下载均可立即操作），首页数据在框架内以骨架屏占位加载。
5. **骨架屏加载提示** —— 多源加载时显示“正在从 N 个站源加载，可先看其他标签”。

性能优化：

6. **Dart AOT 混淆与符号剥离**（`--obfuscate --split-debug-info`），缩减 libapp.so 并加快加载。
7. **Go 核心软内存上限 512MB**（`native/core/app_memory_limit.go`），约束堆水位，降低与视频解码库共存时被系统查杀的概率。
8. **图片缓存峰值收敛 100MB → 64MB**（封面已按 440 宽下采样）。
9. **启动路径并行化**（SharedPreferences 与设备检测并行执行）。
10. **首页网格 RepaintBoundary 重绘隔离**。
11. **下一集预载触发提前 600ms → 350ms**（保留防抖）。
12. **多源目录并发提升** —— Go 全局目录并发 3 → 6、同源请求间隔 250ms → 150ms（均在原设置项允许范围内），Dart 目录 worker 并发 2 → 6。

构建修正：

13. **锁文件保持上游原版** —— 全程使用 `--enforce-lockfile` 由构建脚本镜像转换，杜绝依赖漂移（曾因手动 `pub get` 导致 `shared_preferences_android` 升到 2.5.0，与混淆构建冲突引发启动崩溃，已修复并回归锁定 2.4.28）。**构建时请勿绕过构建脚本手动执行 `flutter pub get`。**
14. **Release 签名方案说明** —— 自行构建时可用 `apksigner` 附加 `--v1-signing-enabled true --v2-signing-enabled true --v3-signing-enabled true`，对各类安装器有更好的兼容性。

**融合新增（v0.7.16+76a）：**

15. **弹幕（仅红果源）** —— 由 v0.2.x 移植的弹幕功能：竖屏与全屏播放器控件条均提供独立「弹幕」按钮（免进倍速菜单），红果分集按时间窗拉取弹幕并随播放进度滚动；弹幕开关持久化。
16. **站源密码锁** —— 底部导航连点「最近观看」6 次唤出密码锁弹窗。默认只显示 4 个常用源（红果/韩小圈/鬼片/青空），其余敏感源需启用密码锁并解锁后显示；也可关闭密码功能直接显示全部源。解锁状态仅本次运行有效，重启恢复默认。
17. **新增 5 个扩展站源** —— 韩小圈、鬼片、青空、野果、帝果（接入目录/搜索/详情/榜单/取流全链路）。
18. **剔除失效站源** —— 经真实接口连通性探测，帝果（`dsd.com.se`）域名已失效，从源列表中移除（保留源码 provider 便于日后恢复）。
19. **版本命名规则** —— 本地增强版沿用「上游版本号 + a」（如 v0.7.16+76a），与上游版本严格区分；versionCode 保持递增可覆盖安装。

**保留上游 0.7.x 全部官方功能与修复**，包括：0.7.16 红果站源完整六头签名修复与开屏超时兜底、0.7.15 切集闪帧修复、0.7.14 连播跟手动画、0.7.13 预加载提前到开播 3 秒、0.7.12 方向锁定手势与移动网络只拦第 1 个视频、0.7.10-0.7.11 横屏手势翻页阈值修复、0.7.8 亮度改为窗口亮度（可超过系统亮度）、0.7.5 全屏手势分工与系统音量、0.7.4 全屏连播控件与移动网络切线路修复、0.7.3「移动网络下自动播放」开关与停预加载、0.7.2 全屏横屏手势与首页剧类筛选、0.7.1 自动更新节流、0.7.0 代理失败自动直连与黄果剧场换域名等。

### 手势速查

**竖屏（手机）**：画面上滑下一集、下滑上一集；长按 350 毫秒临时 3 倍速，松开恢复；轻点播放/暂停，双击播放/暂停；进详情页会先暂停，返回后不自动恢复。

**全屏横屏（0.7.2 起）**：左右滑动调进度；左侧上下滑调亮度、右侧上下滑调音量；中间上下滑切上一集/下一集；左上角常显「第 N 集」，自动连播不弹控件，点一下屏幕随时唤出。

**电脑（Windows 版，源码保留，暂停适配）**：空格播放/暂停；← 后退 5 秒，→ 轻按前进 5 秒、长按 3 倍速；↑↓ 调音量；M 静音；F / F11 / Ctrl+F 全屏；Esc 退出全屏或返回。

## 五、从源码构建

需 Go 工具链编译原生核心生成 `libduanju_core.so`（构建脚本自动完成，无需预编译库）。

**环境要求**：Flutter（版本与上游 `pubspec.yaml` 约束一致）+ Go + JDK 17 + Android SDK（platform 36 / build-tools / NDK）。

**步骤**：

1. 配置自己的签名（仓库不含任何密钥）：在 `android/` 下放置你的 `key.properties` 与 keystore 文件；
2. 构建“真果鉴”（全站源）：

   ```sh
   python3 scripts/build_android.py --abi arm64-v8a --all-sources
   ```

3. 构建“红果鉴”独立包名共存版（仅红果源）：先把 `android/app/build.gradle.kts` 中 `applicationId` 改为 `com.duanju.duanju_app.hongguo`，再执行：

   ```sh
   python3 scripts/build_android.py --abi arm64-v8a
   ```

说明：

- **必须在纯英文路径下构建**（中文路径会导致工具链失败）。
- 构建时不要设 HTTP 代理；访问 GitHub 时才需要代理。
- 构建脚本自带国内镜像选项（`--cn-mirrors`）与锁文件防漂移保护，请勿绕过脚本手动执行 `flutter pub get`。
- 产物在 `dist/android/`，可按第三章第 14 条用 `apksigner` 附加 v1+v2+v3 完整签名。
- 32 位设备把 `--abi` 换成 `armeabi-v7a` 即可。

**源码结构**：

| 目录 | 内容 |
| --- | --- |
| `lib/` | 页面、播放器、本地用户、FFI、下载与媒体处理 |
| `native/core/`、`native/bridge/` | Go 站源核心、缓存、下载与 C ABI |
| `android/`、`windows/`、`ios/` | 平台工程与必要资源 |
| `scripts/` | 构建与签名脚本 |
| `test/`、`integration_test/` | 自动化与设备回归 |
